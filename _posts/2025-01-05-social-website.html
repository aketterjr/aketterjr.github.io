In my free time I enjoy drawing and reading comics and novels, and am currently working on some stories of my own. These hobbies have inspired me to make a publishing company where authors from diverse backgrounds can come together and share their stories with a broader audience. This vision is the foundation of my website and what I am striving to achieve through this project.

Technical Details

Backend, Django REST Framework:

The backend leverages Django for its rapid development capabilities and modular structure. Django's batteries included design philosophy has enabled me to quickly implement features such as user login and registration, as well as staff accounts and moderation using the Django Admin panel.

Djagno Admin Panel The Login Page

In addition to this, I have utilized Django's Object Relational Mapping (ORM) to interact with a Relational (SQLite) Database during development. Here's a look at some of the models I have created:

Models:

  • Books: Tracks book details such as title, author and genre. Fields such as author use a Django ForeignKey to represent their Many-to-One (many books to one author) relationship, while fields such as genre use a Many-To-Many relationship (many genres for one book, and many books for each genre).
    • My Book Model
  • Posts: Includes user generated content tied to discussion threads and topics. Also includes comments which are a Many-To-One relationship (many comments to one post).
    • My Post and Comment Models

Serializers and Views:

In addition to this I have worked on Serializers which organize data into JSON for communication with the frontend. Furthermore, I have built Django Views, which are API endpoints that can be called by the front end.

  • Post and Book Serializers: Designed to Handle post objects, the post serializer formats data fields such as id, title, content, created_at (date and time), and author for API responses. The book serializer similarly includes fields needed by the front end.
  • Post Create View: This view is a REST API endpoint that creates a post in the database. It checks that the user is logged in using the [IsAuthenticated] permission class, then saves the data in the request using the Django .save() method.

Frontend, React.js:

For the frontend I am utilizing React.js to build dynamic user interfaces. So far I have successfully integrated my Django API using Axios, allowing for seamless communication between the frontend and backend.

One feature I'm currently refining is the Carousel on the homepage. While implementing it I ran into an issue where, after displaying the last component, the Carousel jumps all the way back to the first element. This is quite abrupt, and I think it would be better if it faded out, then faded back in with the first element. That is one of the things I am currently working on, as well as adding images for each book to make the user interface more appealing.

The current implementation of the Carousel (book names are placeholders from public domain books)

I have a simple user interface for the posts feature, which shows all posts that have been made on the website. Instead, I want to organize the posts into forums enabling easier navigation. Lastly, I am refactoring the front end so that the user can only see the delete button for posts that they have made.

Lessons Learned:

As I develop this project, I have learned valuable lessons in full-stack development and project management. On the technical side, I've deepened my knowledge of Django's powerful features by integrating these into a functional web application. This has taught me how to effectively design data models and work with complex data relationships, such as Many-to-Many and Many-to-One.

Frontend development with React.js has been a rewarding challenge, especially when managing asynchronous data via Axios. One key lesson has been the importance of creating smooth and intuitive user interfaces, as I continue to refine features like the carousel and the post orgnaization system. I am learning to refine both functionality and user experience.
