While at SMU, I had the opportunity to take CS 2240 - Assembly Language Programming and Machine Organization. This course provided a deep dive into computer-related number systems, machine arithmetic, computer instruction sets, low-level programming, addressing modes, and internal data representation. It was a hands-on exploration of how computers operate at a fundamental level, focusing on the interaction between hardware and software.

Key Projects and Skills Gained:

  1. Developed software using C and ARM Assembly to implement embedded system functions, including a real-time clock.
  2. Implemented a lightweight operating system in Assembly to control an STM32F4 microcontroller.
      3. Key Features:
    • A spinning triangle display to showcase graphical rendering on the microcontroller.
    • Prime number calculation, demonstrating proficiency in low-level algorithm design and execution.
  3. Enhanced processor performance by implementing efficient low-level algorithms, which improved execution speed and optimized resource utilization.

Lessons Learned:

This course challenged me to think critically about the relationship between software and hardware. Designing and debugging in Assembly required meticulous attention to detail and a comprehensive understanding of the architecture of the STM32F4 microcontroller. The experience solidified my interest in low-level programming and embedded systems, equipping me with the skills to tackle complex hardware-software integration challenges in the future.
